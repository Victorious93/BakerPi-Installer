Install profiles

A profile is a named set of tools. Apply installs every tool in it, in order, on the current target device(s) (the selected devices). Choose targets in the Devices panel.
Profiles hold tool ids only (no passwords or hosts) and are stored per user, outside the repo. Profile apply is untested on real Pi Zero hardware.

 Fleet Firmware (VictorModem / Pyra Claw)
            UNTESTED ON HARDWARE

          
Neither project publishes release
            binaries: build with PlatformIO first, then point at .pio/build/<env>/ or upload the .bin files.
            Uses the port and baud picked above.

          

            

            

            

              

          

          

          
boot_app0.bin is usually not in
            .pio/build/<env>/: it ships with the Arduino-ESP32 framework
            (~/.platformio/packages/framework-arduinoespressif32/tools/partitions/boot_app0.bin).
            Upload it here if it isn't found; if it is skipped, OTA boot selection data at 0xe000 is left as-is.

          

            
            
          

          

          
Serial monitor: after flashing, open a
            serial monitor (e.g. pio device monitor -b 115200) for logs. Use USB Provisioning
            below to configure a board running firmware with serial provisioning. Offsets are not verified on hardware.

        

        
        

          
 USB Provisioning (VictorModem / Pyra Claw)
            UNTESTED ON HARDWARE

          
Uses the port picked above, 115200 baud.
            The board must run firmware with serial provisioning (Pyra Claw: merged; VictorModem: PR #3, not merged).
            It accepts commands for 10 s after boot, or any time while unprovisioned. Changes apply after a reboot.
            Secrets are never shown or prefilled; leave a secret blank to keep it (Pyra Claw only).
